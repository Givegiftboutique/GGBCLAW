# Fallback Behavior Notes

- `?source=mock` uses inline mock data.
- `?source=json` loads `./data/dashboard-export.sample.json`.
- `?source=artifact` loads `./data/dashboard-artifact-manifest.sample.json`.
- Failed fetch or validation falls back to mock data.
- Fallback status uses health `warning`, fallback `mock`, and a visible fallback reason.

# Source Adapter Decision Record

Local static JSON and artifact manifest sources are useful for manual review and evidence replay without introducing live runtime risk. OpenClaw Gateway remains a future read-only adapter design and is not wired here.
